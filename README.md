# Asteroids

A simple Asteroids-style game written in C++ using SFML.
Game still contains bugs. 
## Requirements

* C++ compiler
* CMake
* SFML

## Build

From the project root, create and build the project with CMake:

```bash
cmake -S . -B build
cmake --build build
```

## Run

After building, run the game with:

```bash
./build/bin/asteroids
```
